# Oluebube Cynthia Okekeudoh — COS 106 Portfolio

A responsive multi-page student portfolio and academic management website built with HTML, CSS and JavaScript for the COS 106 Introduction to Web Technologies term project.

## Pages
- `index.html` — homepage, profile image, welcome message and navigation
- `about.html` — education table, career aspirations, skills, interests and HTML5 video
- `projects.html` — three illustrative cybersecurity project concepts and links
- `planner.html` — add, complete and delete tasks; tasks persist in browser local storage
- `contact.html` — required contact form with JavaScript validation





## Assessment alignment checklist
- Homepage: name, portrait, welcome, navigation, biography, professional layout
- About: education, career goals, technical learning areas, interests
- Projects: three project entries, descriptions, illustrations and links
- Academic planner: add, mark complete, delete, dynamic rendering and local storage
- Contact: name, email, phone, message; JavaScript required-field, email and digits-only phone validation
- Technical evidence: semantic HTML, forms, table, images, links, list, video, external CSS, responsive CSS, Grid/Flexbox, transitions, event handlers, DOM updates, arrays and functions

**Important:** Project cards are starter concepts, not claims of completed work. Update them as you complete your own labs.
